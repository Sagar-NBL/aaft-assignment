# AAFT LMS — Backend Assignment Repository

Reference frontend and documentation for the AAFT Enterprise LMS backend developer assignment. Implement your API in [`backend/`](./backend/).

## Documentation

| Document | Purpose |
|----------|---------|
| **[ASSIGNMENT.md](./ASSIGNMENT.md)** | Complete assignment brief, API contract, and reference frontend guide |
| **[backend/README.md](./backend/README.md)** | Where to implement your NestJS/Express service |

## Run the reference frontend

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). See [ASSIGNMENT.md](./ASSIGNMENT.md) for demo accounts and full details.
